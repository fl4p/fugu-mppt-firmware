# pprof.conf

Sampling profiler.

| key            | unit | type | default | description                                                             |
|----------------|------|------|---------|-------------------------------------------------------------------------|
| `sprofiler_hz` | Hz   | int  | 0       | Sampling profiler frequency, ~100–300 (needs OpenOCD attached); 0 = off |
