# Documentation site

Docusaurus site with its pages in `docs/`: five sidebars (`guide/`, `reference/`, `internals/`, `lab/`,
`development/`), each autogenerated from its folder.

```bash
npm ci
npm start        # live preview at http://localhost:3000/fugu-mppt-firmware/
npm run build    # static site in build/; fails on broken links
```

To add a page, create `docs/<section>/<name>.md` with `title:` and `sidebar_position:` front matter. Folders get
their label and position from `_category_.json`. Pages must stay generic: no device names, IPs, hosts or
credentials. Lab-specific notes go to `../doc/lab/`, which is not published.

Relative links to repo files outside `docs/` (source, configs, `doc/`) are rewritten to GitHub URLs by
`src/remark/repo-links.mjs`, which fails the build if the target does not exist.

`.github/workflows/docs.yml` deploys to GitHub Pages on pushes to `main` that touch `website/`.
