Config Editor Help

Open ZIP/Folder: Load configuration files from a ZIP archive or select .conf files

Edit: Each .conf file gets a tab. Change values and see the dot indicator.

Units: Displayed inside input fields (GPIO, Hz, Ω, V, A, etc.)

Side keys: sensor.conf and limits.conf name channels and limits by side (hv_v_rh, lv_i_factor, hv_max, lv_i_max); converter.conf topo maps sides to roles. Legacy role keys (vin_rh, vout_max, ...) still load, but each file must use one form throughout.

Clear (×): Removes a value (shows "was: ..." below)

Serial: Connect via Web Serial API (115200 baud) to read/write configs

BLE: Connect via Nordic UART Service to read/write configs

Download: Save all changes as a ZIP file
